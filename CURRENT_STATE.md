# TopPay 3.0 — Current Project State & Memory

This file serves as memory for AI agents. When a new conversation starts, read this
to understand the current state of the project.

## Project overview

TopPay is a mobile-first payment account platform served from `www.web-toppay.in`.
The repository contains three surfaces plus a set of static SEO pages:

| Surface | Path | Notes |
|---|---|---|
| Public SEO pages | `public/*.html` | Generated by `seo-generator.cjs` — never edit by hand |
| User app | `user-app/` | Login, home, MPIN. `/` rewrites to `user-app/pages/login.html` |
| Admin panel | `admin-app/` | Reached via `/admin` rewrite |
| Shared code | `shared/`, `supabase/` | Auth guards, Supabase client, UI helpers |

## Build & deploy

- **Build:** Vite. `npm run build` runs `prebuild` → `seo-generator.cjs` → `vite build`.
- **Output:** `dist/` (set as `outputDirectory` in `vercel.json`).
- **Host:** Vercel, project `toppay3-0`.
- **Routing:** rewrites and redirects live in `vercel.json`. `/` → `user-app/pages/login.html`,
  `/admin` → `admin-app/pages/login.html`.
- **Scripts:** always use `type="module"` on `<script>` tags that need Vite bundling in
  production, otherwise Vite drops them.

## SEO configuration

- **Canonical URL form is `.html`** — e.g. `https://www.web-toppay.in/toppay-usdt.html`.
  Extensionless variants (`/toppay-usdt`) 301-redirect to the `.html` form via `vercel.json`.
  **Do not change this URL structure.** Each change resets Google's migration clock and
  costs weeks of ranking while signals transfer between URLs.
- **`robots.txt` and `sitemap.xml` are generated** by `seo-generator.cjs` and
  `generate-sitemap.cjs`. Editing `public/robots.txt` or `public/sitemap.xml` directly is
  useless — the next build overwrites them. Edit the generators instead.
- **Only `/admin`, `/admin-app/` and `/user-app/` are disallowed in robots.txt.**
  `/portal.html` (301s to `/`), `/404.html` and `/offline.html` (both carry
  `noindex, follow`) are deliberately left crawlable. A blocked URL can never be crawled,
  so Google never sees the redirect or the noindex and the URL stays stuck in
  "Blocked by robots.txt" indefinitely.
- **Sitemap must contain only final, non-redirecting URLs.** `generate-sitemap.cjs` throws
  a build error if a redirecting URL sneaks in.
- Target keywords: `Toppay`, `Toppay login`, `Toppay app`, `Toppay apk`,
  `Toppay app download`, `Top pay`, `Toppay usdt`, `Toppay real or fake`.

## Known cleanup items

- `app/`, `.next/` and `next.config.mjs` are leftovers from an abandoned Next.js
  experiment. The live deploy is a static Vite build, so the `app/api/*` route handlers
  never execute — they are dead code and can be removed.
- `vite.config.ts` builds every `.html` file it finds recursively. Any scratch or vendored
  project folder dropped into the repo root will be built and deployed to the live domain.
  Add such folder names to the exclusion list in `getHtmlFiles()`.

## Environment

- **OS:** Windows, PowerShell.
- **Database:** Supabase. Ensure RLS policies or correct tokens are used.
- **Admin sessions:** `admin_sessions` table tracks multi-device login. Changing an admin
  password logs out all other devices. `auth.js` handles a missing table gracefully without
  causing infinite logout loops.
